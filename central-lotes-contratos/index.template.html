Dicionário rápido

SHA-256

Identificador calculado a partir do conteúdo. Ajuda a detectar se um arquivo mudou. Um hash informado manualmente não equivale à verificação do arquivo real.

Checkpoint

Registro de onde o processo parou e de quais contratos já foram confirmados. Para troca de computador, precisa existir fora do navegador.

Idempotência

Repetir uma operação sem criar contratos duplicados. Exige uma chave única também no sistema de destino.

LGPD

Lei Geral de Proteção de Dados. Aqui significa não guardar dados pessoais ou senhas sem necessidade, limitar o acesso e manter rastreabilidade.

Fail-closed

Quando falta prova, acesso ou autorização, o sistema interrompe a ação arriscada em vez de prosseguir por suposição.

Preflight / retry / backoff

Preflight é a conferência prévia. Retry é uma nova tentativa após falha temporária. Backoff é esperar mais antes de tentar novamente.
